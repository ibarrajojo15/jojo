# Jerseys Barato — jersey storefront mock-up

An interactive, self-contained prototype of a bilingual (EN/ES) soccer,
basketball and American-football jersey storefront, plus a custom
team-kit bulk section. Everything runs client-side in a single
`index.html` with inline CSS and vanilla JavaScript — no build step.

This is a **mock-up with placeholder imagery and prices**, not the live
store. Real product photos and pricing are still to come.

## Run it

Open `index.html` in any modern browser. No server or dependencies
required (a Google Fonts link is the only external resource).

## What's inside

- 360° drag-to-spin jersey hero with three swappable colorways
- Live customizer: color, size (S–XXL), custom name and number on the kit
- Categories: Soccer, Basketball, American Football, and Custom Team Kits
- Custom team-kit / bulk section with logo upload and quantity tiers
- Always-on deal banner that routes to the Sale collection
- Hub / news feed and @jerseys_barato Instagram link
- Slide-in cart with a mock client-side checkout flow
- Three themes (Light / Dark / Glass) and instant EN/ES language toggle
